# مشخصات فاز اول

پنل تک‌مدیره، فارسی و راست‌به‌چپ برای داده‌های آزمایشی با Laravel 13/PHP 8.3، Blade/Tailwind، MySQL 8.4 و صف دیتابیسی. تصمیم کاربر، دسترس‌پذیری پروژه و وضعیت ارسال جدا هستند؛ داده ناموجود حدس زده نمی‌شود؛ ورودی پروژه/مدل غیرقابل‌اعتماد است؛ CAPTCHA دور زده نمی‌شود.

مرز اتصال: `KARLANCER_MODE=mock`، `LLM_MODE=mock` و `REAL_SUBMISSIONS_ENABLED=false`. هیچ کلاینت واقعی یا مسیر ارسال در این فاز وجود ندارد.

## matching فاز ۳A

پروفایل واحد مدیر در `matching_profiles` نگهداری می‌شود و نتیجه هر پروژه در `project_matches` با امتیاز، breakdown، زمان و `source_hash` ذخیره می‌شود. hash از فیلدهای مؤثر پروژه و ترجیحات ساخته می‌شود؛ صفحه توصیه‌ها فقط رکوردهای stale را محاسبه می‌کند و دکمه محاسبه مجدد همه پروژه‌های mock را به‌صورت دستی به‌روزرسانی می‌کند. این persistence وضعیت پروژه و تاریخچه فعالیت را تغییر نمی‌دهد.

وزن‌ها: هم‌پوشانی مهارت ۴۵، کلیدواژه مثبت ۲۵، بودجه سازگار ۲۰، bonus تکمیل معیارهای مثبت ۱۰، و جریمه کلیدواژه منفی تا ۳۰. تطبیق متن deterministic و بدون API خارجی است؛ واحدهای پول هرگز تبدیل یا حدس زده نمی‌شوند.
