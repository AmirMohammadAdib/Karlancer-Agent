# پژوهش اتصال کارلنسر

تاریخ بررسی: ۱۵ اکتبر ۲۰۲۶.

## یافته‌های قابل‌تأیید

- [صفحه اصلی کارلنسر](https://www.karlancer.com/) بازار پروژه و فریلنسری و مسیرهای عمومی ثبت پروژه و ورود را معرفی می‌کند؛ در بررسی انجام‌شده مستندات عمومی API یا feed رسمی برای دریافت پروژه پیدا نشد.
- [قوانین و شرایط](https://www.karlancer.com/terms) در دسترس عمومی است، اما در بخش‌های بررسی‌شده API عمومی، feed داده یا مجوز جمع‌آوری خودکار پروژه‌ها اعلام نشده است.
- جست‌وجوی منابع رسمی برای API، شرایط استفاده و feed نتیجه قابل اتکایی نداشت؛ وجود API عمومی، export مجاز، سهمیه/نرخ درخواست و احراز هویت برنامه‌ای تأیید نشده است.
- آدرس `https://karlancer.com/robots.txt` در ابزار بررسی قابل دسترس نبود و صفحه اصلی به `www.karlancer.com` هدایت شد. robots.txt به‌تنهایی مجوز crawl یا scraping نیست.

## موارد نامعلوم و سیاست ایمنی

شرایط استفاده، محدودیت‌های robots، نرخ درخواست، استفاده از داده و نیاز به اجازه صریح مالک سرویس از منبع رسمی قابل راستی‌آزمایی نبود. تا دریافت مستندات یا اجازه کتبی، هیچ connector زنده، درخواست HTTP، مهندسی معکوس endpoint خصوصی، دورزدن CAPTCHA یا احراز هویت اجرا نمی‌شود. این فاز فقط fixture محلی دارد.
